# M4 reviewer-package policy — V3 + REC / Ecological Informatics

Status: **fail-closed package policy for third-party data and double-anonymous review preparation**.

## Purpose

The M4 reviewer package must allow a reviewer to inspect and reproduce the manuscript-facing analyses without silently redistributing third-party source files whose repository-level reuse terms are not explicit.

## Allowed package content

The package may include:

- `manuscript/M4_V3_REC_DRAFT_V1.md` or its anonymous journal-facing derivative;
- `manuscript/M4_V3_REC_CLAIM_MANIFEST.json`;
- V3 source/code required for the frozen synthetic strict-refinement result;
- REC analysis scripts required to regenerate manuscript-facing summaries;
- pinned result JSON files produced by REC analyses;
- source commit/blob identifiers for Findlay data;
- download instructions that retrieve the original Findlay files from the authors' public repository;
- integrity checks that verify the exact source commit/blob identities;
- BirdVox-derived files whose redistribution is compatible with the documented CC BY 4.0 source licence;
- figure-data sidecars and deterministic figure-generation code;
- third-party-data rights notes and citations.

## Forbidden package content unless rights are clarified

Do **not** include copies of the original Findlay source CSV files, including at minimum:

- `REGISTRATION_FOX_BADGER.csv`;
- `TRIGGER_OTTER_WET.DRY.csv`.

Do not rename, transform or embed those original files as a way to bypass this rule. A derived numerical summary generated by our analysis is different from redistribution of the original source file and may be included when it contains only manuscript-facing derived quantities.

## Required Findlay provenance

The package/reproduction instructions must identify:

- source repository: `melaniefindlay/CT-Detection`;
- frozen source commit: `abc72f535bb59ebed202fb7acca852fc1647e97a`;
- exact source filenames used;
- the source paper and DOI;
- the fact that the article is CC BY 4.0 and explicitly identifies the GitHub repository as its online R/data resource;
- the residual caveat that the GitHub repository itself does not display an explicit root licence.

## Reproduction contract

A reviewer who has network access should be able to:

1. run the provided acquisition helper or follow the pinned download instructions;
2. obtain the two source files from the authors' original repository;
3. verify the frozen commit/blob identities;
4. run the REC analysis code;
5. reproduce the derived manuscript-facing JSON summaries and figures.

If journal review infrastructure requires a self-contained offline archive, do not insert the source CSVs automatically. Resolve the data-owner/licence question first or ask the journal whether source-repository retrieval is acceptable for review.

## Scientific claim firewall

The reviewer package must preserve the same claim boundaries as the manuscript:

- V3 strict refinement remains controlled/synthetic;
- REC Findlay results remain reanalyses of the source authors' camera-trap reference system;
- BirdVox irreversibility remains bounded to the protected acoustic system;
- recovery remains transport-limited and includes the adverse double-holdout result;
- TNOA semantic-restraint/coarsening material is not part of M4.

## Package gate

Before an M4 review package is released, verify:

- [ ] no original Findlay CSV is present anywhere in the archive;
- [ ] no author-identifying literals remain if double-anonymous review applies;
- [ ] every quantitative manuscript result has a pinned derived source;
- [ ] download/provenance instructions identify the exact Findlay commit/files;
- [ ] the rights note is included;
- [ ] the package reproduces the submitted figure/result surface from safe inputs.
