# AI / LLM disclosure draft — author confirmation required

Status: **draft only; not yet licensed for insertion into the submitted manuscript**.

Methods in Ecology and Evolution currently requires a clear Methods statement when LLMs or comparable AI tools were used to produce manuscript work, including the application name/version. The journal also requires a corresponding or senior author to take responsibility for generated code/text and notes that LLM-generated code should be annotated where required.

## Factual draft

> OpenAI ChatGPT (GPT-5.6 Sol) was used during code review, debugging, and manuscript drafting and editing. Mathematical claims, numerical outputs, machine-readable result summaries, and manuscript-facing values were checked against executable source artifacts and automated tests/continuous integration. The responsible author(s) reviewed and take responsibility for the submitted text and code.

## Before insertion

The authors must confirm:

1. that this wording accurately describes the extent of use;
2. which corresponding or senior author accepts the journal-required responsibility;
3. whether any source files need explicit annotations for LLM-assisted code under journal policy;
4. that all authors approve the final disclosure and submitted material.

Do not infer or insert the responsible author's identity from repository metadata.
