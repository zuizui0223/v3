# Declaration of generative AI and AI-assisted technologies in the manuscript preparation process — template

Status: **human metadata required before submission**.

Elsevier's current journal policy requires a separate declaration when generative-AI tools make substantive contributions to manuscript preparation. This template is intentionally not finalized because the exact tool/model versions and the final scope of use must be confirmed by the responsible author immediately before submission.

Insert the finalized declaration in the manuscript immediately before the References, using the journal's required heading for generative-AI disclosure.
