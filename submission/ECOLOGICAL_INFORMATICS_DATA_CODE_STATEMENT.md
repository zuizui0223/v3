# Data and code availability — M4 draft

The manuscript combines controlled synthetic results with reanalyses of publicly available third-party ecological datasets. All manuscript-facing quantitative results are linked to pinned source artifacts and deterministic analysis code.

## V3 controlled system

The controlled retained-reference benchmark, figure data and analysis code are contained in the V3 reproducibility materials. These results are synthetic/controlled validation and are not presented as field-performance measurements.

## BirdVox

The acoustic reanalysis uses BirdVox-full-night v3.0, which is distributed through Zenodo under CC BY 4.0. The final manuscript will cite the dataset and retain the required attribution/licence wording.

## Findlay camera-trap source

The camera-trap reanalysis uses the public `melaniefindlay/CT-Detection` repository associated with Findlay, Briers & White (2020). The source article is CC BY 4.0 and explicitly identifies that repository as the online location of the article's R file and datasets. The analyses use the frozen source commit `abc72f535bb59ebed202fb7acca852fc1647e97a`, including `REGISTRATION_FOX_BADGER.csv` and `TRIGGER_OTTER_WET.DRY.csv`.

Because the GitHub repository itself does not currently display an explicit root licence, our review/public reproducibility package will **not redistribute copies of the original Findlay CSV files** unless repository-level terms are clarified. Instead, the package will provide the analysis code, exact source commit/file identities, acquisition instructions and integrity checks needed to retrieve those files from the authors' original repository, together with the derived manuscript-facing summaries and figures generated by our analyses.

## Version-of-record archive

The final public code/result snapshot and persistent identifier will be fixed once the submitted manuscript and review package are frozen. Third-party data will remain governed by their original licences/owner terms and will not be relicensed by us.
