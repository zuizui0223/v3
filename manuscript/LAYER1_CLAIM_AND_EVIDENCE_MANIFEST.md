## Primary claims

### C1 — compatible-world observation theory

A retained observation map induces compatible-world fibres and identified sets; observation-system operations can be compared by how they refine or merge those fibres.

Evidence: T1–T23.

### C2 — retained information can strictly refine

Weak refinement is structural; U1 provides an exact finite-world case where a discriminating retained reference contracts compatible-set size `2 -> 1`, while a constant reference leaves `2 -> 2`.

### C3 — support deletion creates a qualitatively different loss

U2 shows two full opportunity worlds with identical selected tables but full-prevalence values `0.50` and `0.75`. A denominator ledger alone preserves the width `0.25`; an independent omitted-truth audit collapses it to zero.

### C4 — semantic coarsening can strictly destroy identification

U3 maps two distinct rich evidence states to one binary state, increasing compatible-set size `1 -> 2` and truth-set width `0 -> 1`.

### C5 — prospective acquisition is expected refinement

U4 gives candidate information values `1.0`, `0.811278...`, and `0` bits. Information-guided choice obtains `1` bit immediate expected reduction versus `0.603759...` bits under uniform random candidate choice. A second complementary observation yields entropy path `2 -> 1 -> 0` bits.

### C6 — interventions can add identification directions

U5 begins with four statically equivalent mechanisms. One binary intervention produces two groups of size two; two orthogonal intervention responses yield four singleton signatures and entropy path `2 -> 1 -> 0` bits.

### C7 — information loss cannot be repaired by semantics alone

T16/T23 plus U2/U3: deterministic downstream processing of an already collapsed state cannot recreate a lost distinction; recovery requires independently retained or newly acquired information that separates the previously equivalent worlds.

## Claims that are intentionally not made

The paper does not claim:

- that the individual mathematical foundations are newly invented;
- physical reference effectiveness;
- ecological field accuracy;
- universal benefit of richer representations for every implemented learner;
- universal optimality of information-guided observation design;
- equivalence of rank, entropy and identified-set width;
- completeness of a mechanism vocabulary in nature;
- natural causal identification from compatible-world geometry alone.
