## Paper question

> How does an ecological observation system change the scientific distinctions preserved in the retained record as information is added, support is selected, and evidence is semantically coarsened?

## Primary claim spine

1. **Refinement** — retaining an additional justified channel weakly contracts compatible-world and identified sets; strict benefit is channel- and estimand-dependent.
2. **Selection** — opportunities that fail to become rows remove support in a way that cannot be reconstructed from the selected event table alone.
3. **Coarsening** — deterministic semantic simplification can merge scientifically distinct worlds that remained separable in the richer retained record.
4. **Irreversibility** — deterministic downstream processing of a collapsed record cannot restore a distinction that the retained object no longer contains; recovery requires independent/new information.

### O-R3 — TNOA semantic-coarsening stress test

## Manuscript structure

### Introduction

1. observation-system error is not one classifier-accuracy problem;
2. information can be added, support can disappear, and retained evidence can be collapsed;
3. these operations act differently on compatible worlds;
4. the paper unifies them and tests them from exact synthetic worlds through external empirical data.

### Methods

1. compatible worlds and identified sets;
2. refinement operator;
3. selection/support-loss operator;
4. semantic coarsening operator;
5. irreversible versus reversible transformations;
6. validation hierarchy and source-provenance rules.

### Results

1. retained side information can strictly refine when informative;
2. record-entry selection changes an ecological estimand in external data;
3. omitted support is not reconstructed by perfect downstream semantics;
4. semantic coarsening materially widens a known-truth target identified set;
5. correction and refinement have explicit calibration/transport domains.

### Discussion

Lead with the scientific consequence:

> Observation quality is not exhausted by detector accuracy. The retained scientific record is shaped by when information is added, when support is deleted, and when evidence is collapsed.

End by handing the retained compatible-world set to Evidence rather than solving evidence licensing inside this paper.

## Cross-paper firewall

Observation may say:

> After observation-system transformations, a compatible-world/identified set remains.

Observation may not own:

- current mechanism-rank boundary as a separate novelty result;
- optimal future measurement choice;
- target-safe quotient/reportability;
- false-resolution risk/cost stopping.

Those belong to Evidence.
